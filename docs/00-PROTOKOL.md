## 2 · КАКВО ПАЗИ ПОРТАТА

`npm run protokol` брои и пада, ако:

1. **ред без платена цена** — вид работа, обявен без грешката, която го е родила;
2. **ред без задължително четене** — празен списък;
3. **ред без „как се познава, че е спазено"**;
4. **посочен файл, който го няма** — протокол, който сочи в празното, е по-лош от липсващ;
5. **вид работа без белег** (`У` + число);
6. **променен файл без освежен отпечатък** — моделът на работа се мени само с вдигната
   версия и записан довод.

Числото на видовете се БРОИ от самия файл (правило 14), не се преписва тук.
