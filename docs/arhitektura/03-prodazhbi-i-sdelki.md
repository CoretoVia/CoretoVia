## M03 · АРХИТЕКТУРНИЯТ КЪС · Продажби и сделки

### 1 · СЪЩНОСТИТЕ

Продажбата НЕ е отделна същност в Журнала. Тя е **РЕД в таблица** — както всичко
останало (К1 · ADR-003: моделът е данни). В Журнала живеят само СЪБИТИЯ за редове
и клетки; „Продажба" е ПРОЧИТ над тях.

| същност | къде живее | родител | полета |
| :---- | :---- | :---- | :---- |
| **Tablitsa `prodazhbi`** | `src/model/osnova.ts` (замразен низ с контролна сума · К3) | прозорецът `prodazhbi` | ключ · неговата лента дословно · 20 колони |
| **Tablitsa `prodazhbi2`** | същото | същият прозорец | ключ · неговата лента дословно · 20 колони |
| **Kolona** | `src/model/kolona.ts` | таблицата | `klyuch` · `ime` (негов, дословно) · `vid` · `merka` · `zatvorena` · **`plashtane: {rolya: цена\|вноска\|проверка, strana: банка\|кеш}`** · **`zavarshva`** |
| **Ред-продажба** | Журналът, като събития | таблицата (`tablitsa` в товара) | `id` · `seq` · клетките по ключ на колона |
| **Prodazhba** (прочит) | `src/smetach/prodazhbi.ts` — СМЯТА се, не се пази | реда | `ime` · `kvadratura` (цели кв. см) · `tsena` · `tsenaPoStrani` · `strani[]` · `platena` · `zavarshena` · `chaka[]` |
| **StranaNaProdazhba** (прочит) | същият файл | продажбата | `strana` · `tsena` · `vneseno` · `ostatak` |
| **TablitsaNaProdazhbite** (прочит) | същият файл | прозореца | `obshto` · `kvadratura` · `platenite` · `zavarshenite` · `ostatak` · `sastoyanie` · `sverki[]` |
| **Otsenka** (прочит · Калкулатор) | `src/smetach/kalkulator/stoynost.ts` | продажбата | `vid` · `poDumata` · `pazaren_st` · `dohoden_st` · `razhoden_st` · `saglasuvane` · `dogovorena_st` · `razlika_st` |

**Парите:** всяко парично поле завършва на `_st` и е цели центове. Площта е цели
кв. см. Коефициентите са базисни точки (`_bt`).

### 2 · СЪБИТИЯТА · кое действие какъв тип ражда

| действие на човека | команда | събитие в Журнала |
| :---- | :---- | :---- |
| „Добави продажба · първа сграда" | `prodazhbi.dobaviParva` | **РедЗаписан** (`tablitsa: prodazhbi`) |
| „Добави продажба · втора сграда" | `prodazhbi.dobaviVtora` | **РедЗаписан** (`tablitsa: prodazhbi2`) |
| поправка на клетка (купувач · цена · вноска · дата) | `red.popraviKletka` | **РедЗаписан** (нов такт, старият остава) |
| изключване на ред | `red.izklyuchi` | **РедИзключен** — изключено ≠ липсващо (правило 12) |
| връщане на изключен ред | `red.varni` | **РедЗаписан** |
| сторно на вноска при разваляне | `storno` | **Сторно** — ДОБАВЯ, не отменя (И97) |
| нова стойност в описващо меню (купувач) | през Вратата | **СтойностЗаписана** |
| спиране на сгрешена стойност | през Вратата | **СтойностСпряна** (редовете с нея остават) |
| запис на Книгата | `kniga.iznesi` | **КнигаИзнесена** |
| зареждане на Книгата | `kniga.vnesi` | **КнигаВнесена** |

**Не раждат събитие:** проверката · състоянието на реда · състоянието на таблицата ·
сборът „ОБЩО евро" · цялата оценка на Калкулатора. Те се СМЯТАТ при всяко рисуване.
Сверките се записват като `Sverka` (правило 7), включително когато са нула.
