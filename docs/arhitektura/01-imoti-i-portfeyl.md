## M01 · архитектурен къс

### СЪЩНОСТИТЕ · какво живее в Журнала

Журналът пази СЪБИТИЯ; таблиците са изглед над тях (Огледалото). Три същности принадлежат на M01.

| същност | таблица | id | родител | колони |
| :---- | :---- | :---- | :---- | :---- |
| **Имот** (`imot`) | `imoti` | `imot:‹ключ на действието›` | няма | № (номерация, затворена) · име Имот (текст, зад.) · Състояние (избор → „Състояние на Имот", зад.) · № (число) · площ (число, цели кв. см) · цена (евро, влиза в сбор) · папка в драйва (текст) · адрес гугъл (текст) |
| **Обект** (`obekt`) | `obekti` | `obekt:…` | `imot` → `imoti` | № (затворена) · име Имот (връзка, зад.) · Състояние/категория (избор → „Състояние на Обект", зад., без своя клетка) · Състояние/вид (избор → „Вид на обект", зад.) · № (число, зад.) · площ · цена · папка · адрес |
| **Бизнес** (`biznes`) | `biznesi` | `biznes:…` | `imot` → `imoti` | № (затворена) · име Имот (връзка, зад.) · Състояние Бизнес (избор, зад.) · № Обект (число, зад.) · площ · цена · папка · адрес · други(при нужда) |

**Номерация** (смята се, не се пише): Имот = брояч · Обект = родител · категория · вид · № · Бизнес = родител · 3 · №.

**Номенклатури на темата:** `sastoyanie-na-imot` (ПИ · УПИ · Строеж) · `kategoriya` (Сграда · Паркинг · Бизнес) · `vid-na-obekt`, подредена по `kategoriya` (апартамент · гараж · офис · склад · Хале · НПМ) · `sastoyanie-na-biznes` (ФЕЦ+Батерии · Батерии). Всяка расте САМО от Настройки.

**Не живее в Журнала:** оценката на Калкулатора (тя е СМЕТКА върху живите редове, не запис) и площообразуването, докато не роди Обекти.

### СЪБИТИЯТА · кое действие какъв тип ражда

| действие | тип събитие | товар |
| :---- | :---- | :---- |
| Създай имот · Добави Обект · Добави Бизнес | **РедЗаписан** | таблица · id · клетки |
| Поправка на клетка (име, площ, цена, папка, адрес, Състояние) | **РедЗаписан** | таблица · id · само променените клетки |
| Изключване на ред | **РедИзключен** | таблица · id |
| Връщане на изключен ред | **РедЗаписан** | таблица · id |
| Нова стойност в номенклатура на Състояние | **СтойностНаНоменклатураЗаписана** | номенклатура · номер · текст · белези |
| Спиране на стойност | **СтойностНаНоменклатураСпряна** | номенклатура · номер |
| Поправка на сгрешено събитие | **Сторно** + ново РедЗаписан | правило 1 |
| Внасяне на Книгата с нови Имоти/Обекти | **КнигаВнесена** (после РедЗаписан по ред) | връзка към още неродения родител се разрешава в id преди записа |

Смяната на Състоянието НЕ е свой тип събитие — тя е РедЗаписан върху една клетка. Оценката не е събитие (И131 т.3).

### РЕДЪТ НА ЗАВИСИМОСТИТЕ

Книгата (`.xlsx`) · UI · агент → **един порт** (`src/porta/`) → **един каталог** (`src/komandi/`) → **Вратата** → **Журнал** → **Огледало** → изгледът на трите таблици. Агентът получава `PortaZaChetene` и може само да ПРЕДЛОЖИ нов Имот или Обект (`dryRun`); приема човекът и `actor` е човекът (К3).
