## 2 · СЪБИТИЯТА · кое действие какъв тип ражда

Регистърът има девет типа (`src/sabitiya/registar.ts:16-26`). M08 ползва четири:

| действие | команда | събитие |
| :---- | :---- | :---- |
| нов ред с пари (Заплати Кеш · Фактури Кеш · Фактури Карта) | `komandaZaNovRed('dvizheniya', …)` (`src/komandi/prozortsi/red.ts:351`) | **РедЗаписан** |
| поправка на клетка в ред с пари | `red.popraviKletka` (`red.ts:458`) | **РедЗаписан** |
| изключване / връщане на ред | `red.izklyuchi` \| `red.varni` (`red.ts:578`) | **РедИзключен** |
| сторно на грешен ред | `obshto.storno` (`src/komandi/prozortsi/obshto.ts:33`) | **Сторно** |
| запис на кеша за месеца | `smetki.zapishiKesh` „Запиши кеша за месеца" (`src/komandi/prozortsi/smetki.ts:191`) | **РедЗаписан** (същност `kesh`) |
| запис на ДДС и числата от счетоводството | `smetki.zapishiDds` (`smetki.ts:199`) | **РедЗаписан** (същност `dds`) |
| внос на седмичния файл / извлечението | `kniga.vnesi` (`src/komandi/prozortsi/kniga.ts:139`) | **КнигаВнесена** |
| преименуване / спиране на разходна секция | `nastroyki.preimenuvayStoynost` · `nastroyki.dobaviStoynost` | **СтойностНаНоменклатураЗаписана** · **СтойностНаНоменклатураСпряна** |

**Няма събитие „РедИзтрит".** Триене на ред в Приход/Разход не съществува (р75·[52]).
Сверките НЕ са команда: смятат се и се записват като разписка с разлика, включително нула (правило 7).
