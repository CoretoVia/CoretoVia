## 1 · НАЙ-ТЕЖКОТО, КОЕТО НАМЕРИХА ДОКЛАДИТЕ · и никой не е питал

### 1.1 · ВАЛУТАТА НИКОГА НЕ СЕ ИЗБИРА · петото необратимо

**Правило 3 обещава:** „валутите са две — евро и долар — **избира се една при
регистрация**."

**Проверено на място, три команди:**

```
регистрацията иска ЕДНО поле        interface TovarOtkriy { readonly imeyl: string }
валутата в събитие                  НУЛА попадения в src/sabitiya/ и sabitie.ts
кой подава изрична валута           НУЛА викащи с DOLAR извън valuta.ts
```

Валутата днес е **стойност по подразбиране** в подписа на три функции
(`pari.ts:112` · `:135` · `:191`), и всеки жив викащ ползва подразбирането.

**Четири следствия, всяко тежко:**

| # | какво |
| :--: | :---- |
| 1 | **Долар не може да се избере отникъде.** Обещанието в правило 3 е неизпълнимо |
| 2 | Въведено „1,234.56" по доларовите норми **се чете по евровите и мълчи** |
| 3 | Валутата **не е поле на събитие** → не е в подписа (правило 4) → **не може да се докаже след години в коя валута е писан редът** |
| 4 | `ADR-001:73` вече я е обявила за **настройка** — противоречи на правило 3 („при регистрация") |

**Защо СЕГА:** Журналът е празен. Цената днес е **нула реда**. След първото парично
движение цената е **upcasting на всяко парично събитие** — точно сметката, която ADR-024
направи за другите четири необратими. И У1 („символични цени… ще участват в маркетинга")
значи чужди клиенти, а клиент в САЩ иска долар от първия ден.

**Нито една от шестте оси не е отваряла `src/yadro/valuta.ts`**, а думата „валута" се
среща в `docs/` на ЕДНО място.
